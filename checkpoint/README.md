# checkpoint/

## `AmpGPT2/`

Local snapshot of the published AmpGPT2 model used for sequence generation.

The checkpoint includes model weights, configuration, and tokenizer files so
generation does not require downloading the model at runtime.

The original AmpGPT2 model is available from:
https://imigitlab.uni-muenster.de/heiderlab/ampgpt2

and from Huggingface:
https://huggingface.co/wabu/AmpGPT2
